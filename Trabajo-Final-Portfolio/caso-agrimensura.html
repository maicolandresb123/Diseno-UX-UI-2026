CASO PROFESIONAL · 2026 · SISTEMA PRIVADO

ERP Agrimensura. Un único flujo de trabajo.

Diseño y desarrollo de un sistema para integrar la gestión comercial y operativa de un estudio de agrimensura de Entre Ríos.

Frontend / BackendSQL Servern8nIntegraciones

01 / DESAFÍO

Centralizar información que circulaba entre distintas herramientas.

Un estudio de agrimensura necesita registrar clientes, presupuestos, documentación, trabajos, tareas y estados de trámites. La solución se organizó alrededor de ese recorrido real.

Flujo funcional

  1. Registro de prospecto y cliente.
  2. Presupuestación y apertura del proyecto.
  3. Asignación de tareas y documentación.
  4. Seguimiento, actualizaciones y cierre del trabajo.

Solución

Desarrollo de una aplicación web con frontend, backend y base de datos; integración de eventos y avisos con n8n y bots de Telegram, además de automatizaciones para seguimiento.

Aprendizaje

El valor de un ERP reside tanto en la tecnología como en ordenar la información de acuerdo con las tareas reales de sus usuarios.

Confidencialidad: las capturas fueron compartidas por el autor y anonimizadas antes de publicarse: se ocultan usuario, contraseña, cifras e información operativa. No se difunde el repositorio ni documentación privada.

Interfaz real con datos privados difuminados.
