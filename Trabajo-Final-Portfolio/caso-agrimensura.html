ERP Agrimensura: centralizar el trabajo de un estudio

Diseño y desarrollo de una plataforma para conectar la gestión comercial, tareas, trámites y documentación de proyectos de agrimensura.

Gestión webSQL Servern8n + integracionesImplementación privada

01 · Contexto y necesidad

En un estudio de agrimensura conviven presupuestos, clientes, trabajos de campo, tareas diarias, trámites, documentación y seguimiento de proyectos. Cuando esta información se reparte entre distintos canales, la coordinación se vuelve más difícil.

Objetivo

Crear un flujo de trabajo trazable, desde el ingreso de una oportunidad hasta el seguimiento y cierre de los proyectos, sin perder la documentación asociada.

02 · Funcionalidades trabajadas

01

Centralización

Registro de clientes, contactos, oportunidades, presupuestos, proyectos, tareas y trámites.

02

Seguimiento

Estados y registros que permiten conocer qué trabajo está pendiente, en curso o concluido.

03

Automatización

Flujos con n8n, APIs y notificaciones para conectar acciones y reducir pasos repetitivos.

04

Documentación

Organización de archivos y evidencias vinculadas a tareas y proyectos.

03 · Decisiones y aprendizajes

  • Organizar la experiencia alrededor del ciclo real del trabajo, no de las tecnologías disponibles.
  • Dar prioridad al seguimiento de tareas y a la relación entre proyectos, trámites y documentación.
  • Separar datos de negocio de los flujos de automatización para facilitar el mantenimiento.
  • Diseñar los recorridos de capacitación a partir de tareas reconocibles por los usuarios.

04 · Privacidad y resultados

El sistema está vinculado a un trabajo profesional. Por confidencialidad, el código privado, la base de datos y la información de terceros no se publican en este portfolio.

El resultado documentado es una plataforma orientada a digitalizar el ciclo operativo; no se afirman reducciones cuantificadas de tiempos, costos o errores sin mediciones verificables.

Este caso complementa el caso académico de Cubrí Seguros y permite mostrar otra dimensión del proceso: análisis funcional, sistemas e integración.
