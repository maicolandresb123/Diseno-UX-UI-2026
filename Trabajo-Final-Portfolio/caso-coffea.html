CASO ACADÉMICO · TP4 · 2026

Coffea. Diseño web adaptable.

Reproducción académica de una landing de cafetería, con HTML y CSS, maquetación mediante Grid y Flexbox, y adaptación a distintos dispositivos sin frameworks JavaScript.

HTML5CSS3BEMResponsive
Visitar proyecto publicado ↗Ver código ↗

01 / OBJETIVO

Crear una experiencia web visual y responsive.

Este trabajo de la materia UX/UI consistió en reproducir una landing de cafetería, aplicar HTML5 semántico y estructurar CSS por componentes para que funcione tanto en escritorio como en dispositivos móviles.

Decisiones de implementación

  1. Organización de estilos mediante variables CSS y componentes.
  2. Distribución de contenido con CSS Grid y Flexbox.
  3. Adaptación mobile-first con media queries.
  4. Interacciones básicas sin JavaScript: menú, carruseles y estados de foco.

Aprendizaje

La fidelidad visual necesita una base sólida de estructura, tipografía, espaciado y decisiones responsive. Este proyecto es académico; no se presentan métricas de negocio ni pruebas de usuarios que no se hayan realizado.
