# Evidencias de interfaces SC — v6

## Procedencia
Código fuente del repositorio público `maicolandresb123/Mockups_Ventas` (rama `main`, consultado el 31 de octubre de 2026). Archivos base: `rubros/medica/index.html`, `rubros/hoteleria/index.html`, `rubros/logistica/index.html`, `assets/css/base.css` y controladores JavaScript originales.

## Técnica
Las interfaces se reprodujeron en un entorno de Chromium local a partir del HTML, CSS y JavaScript originales. Se omiten recursos CDN y logos externos que no pudieron descargarse por restricciones de red, y se recorta la zona de navegación sin medios para mostrar la interfaz principal. Las capturas no son fotografías ni maquetas creadas por IA; representan la UI de las demos originales renderizada localmente. Se comprimen en WebP para evitar penalizar el rendimiento.

## Archivos incluidos
- `assets/img/sc-demo-medica-interfaz.webp` — panel de turnos y pacientes con datos simulados.
- `assets/img/sc-demo-hoteleria-interfaz.webp` — reservas y huéspedes con datos simulados.
- `assets/img/sc-demo-logistica-interfaz.webp` — seguimiento logístico con datos simulados.

## Privacidad y límites
No se incorporan capturas de clientes reales. Los números, nombres y operaciones de las demos son ficticios y no deben citarse como resultados de implantaciones. Tampoco se afirma que la UI coincida exactamente con el sitio publicado en una fecha posterior. El código privado de ERP Agrimensura no se hace público.

## Validación UX pendiente
Pruebas con tres usuarios reales, Figma final y Lighthouse en la URL desplegada.
