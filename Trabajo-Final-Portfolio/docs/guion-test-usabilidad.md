# Hito 3 — Guion de pruebas de usabilidad (pendiente de ejecutar)

**Objetivo:** comprobar que usuarios relevantes encuentran información en el portfolio sin asistencia, y recopilar hallazgos que se traduzcan en ajustes antes del deploy final.

**Método propuesto:** prueba moderada individual, **3 participantes reales como mínimo**, sobre prototipo Figma completo (no sobre una propuesta estática). Registrar fecha, perfil no identificable, dispositivo y consentimiento de cada participante. No publicar nombres ni datos personales.

## Tareas

1. «Encontrá en qué empresa trabajó Maikol con sistemas industriales y contame dos actividades que realizó.»
2. «Abrí el proyecto ERP Agrimensura y contame qué problema resuelve.»
3. «Ubicá el certificado de Data Analytics de Coderhouse.»
4. «Encontrá una forma de comunicarte con Maikol.»

Para cada tarea anotar resultado **completa / parcial / no completa**, tiempo aproximado, dudas, clics innecesarios y comentarios literales breves con consentimiento.
