# TP3 — HTML y CSS

Trabajo práctico de la materia **Diseño UX-UI 2026** de la Licenciatura en Sistemas de Información.

## Descripción

El trabajo está compuesto por **20 ejercicios de HTML5 y CSS3**, organizados desde un nivel básico hasta un nivel medio/avanzado. Cada ejercicio se encuentra en una carpeta independiente.

Los ejercicios 1 al 4 trabajan principalmente estructura y elementos HTML. A partir del Ejercicio 5 se incorporan progresivamente estilos CSS, Flexbox, Grid, responsividad, animaciones y otros recursos.

## Decisiones de diseño

Se utilizó **Fórmula 1** como temática visual común en varios ejercicios para mantener una estética coherente y permitir reutilizar una misma línea de contenido mientras se practicaban diferentes técnicas de HTML y CSS.

En los ejercicios responsivos se trabajó principalmente con un enfoque **Desktop First**, partiendo del diseño de escritorio y adaptándolo mediante Media Queries para tablets y dispositivos móviles.

El **Ejercicio 20** funciona como proyecto integrador e incorpora conceptos desarrollados durante el TP, entre ellos Flexbox, CSS Grid, Box Model, variables CSS, posicionamiento, animaciones, menú hamburguesa sin JavaScript, galería tipo masonry, formulario multi-step, scroll-snap y diseño responsivo.

Las imágenes utilizadas incluyen texto alternativo mediante el atributo `alt`, y los formularios utilizan `label` y validación nativa cuando corresponde.
