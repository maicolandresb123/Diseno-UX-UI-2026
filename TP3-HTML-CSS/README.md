# TP3 — HTML y CSS

Trabajo práctico de la materia **Diseño UX-UI 2026**.

## Objetivo

Resolver 20 ejercicios de HTML y CSS organizados en tres niveles:

1. **Nivel básico:** ejercicios 1 al 7.
2. **Nivel intermedio:** ejercicios 8 al 14.
3. **Nivel medio/avanzado:** ejercicios 15 al 20.

## Organización

Cada ejercicio se guardará en una carpeta independiente:

```
ejercicio-01/
  index.html
  styles.css
```

La estructura se irá creando progresivamente a medida que avancemos con cada ejercicio.

## Criterios de trabajo

- HTML5 semántico.
- CSS externo cuando corresponda.
- Código ordenado y comentado.
- Accesibilidad básica.
- Diseño responsivo en los ejercicios que lo requieran.
- Sin agregar complejidad que no pida la consigna.
