# Diseño UX-UI 2026

Repositorio de trabajos prácticos y ejercicios de la cátedra **Diseño UX-UI 2026** de la Licenciatura en Sistemas de Información.

## TP3 — HTML y CSS

Trabajo práctico compuesto por **20 ejercicios completos**, organizados de forma progresiva desde conceptos básicos de HTML5 hasta una landing page integradora con HTML y CSS.

Los ejercicios se encuentran en:

```text
TP3-HTML-CSS/
├── Ejercicio-01/
├── Ejercicio-02/
├── Ejercicio-03/
├── ...
└── Ejercicio-20/
```

Cada carpeta contiene el archivo `index.html` y, cuando la consigna lo requiere, su hoja de estilos CSS correspondiente.

Durante el trabajo se aplicaron conceptos de:

- HTML5 semántico.
- Formularios y validación nativa.
- Box Model.
- Flexbox.
- CSS Grid.
- Pseudo-clases y pseudo-elementos.
- Posicionamiento.
- Variables CSS y modo oscuro.
- Media Queries y diseño responsivo.
- Animaciones con `@keyframes`.
- Menú hamburguesa sin JavaScript.
- Galería tipo masonry.
- Formularios multi-step.
- Landing page integradora.

## Trabajo práctico

La carpeta **TP3-HTML-CSS** contiene los 20 ejercicios y un README específico con la descripción del trabajo y las principales decisiones de diseño.
