# Diseño UX-UI 2026

Repositorio de trabajos prácticos y ejercicios de la cátedra **Diseño UX-UI 2026** de la Licenciatura en Sistemas de Información.

## Contenido

### TP3 — HTML y CSS
Trabajo práctico compuesto por 20 ejercicios progresivos, desde estructura HTML básica hasta una landing page integradora.

Los ejercicios se irán incorporando en carpetas separadas a medida que se resuelvan:

```
TP3-HTML-CSS/
├── ejercicio-01/
├── ejercicio-02/
├── ejercicio-03/
├── ...
└── ejercicio-20/
```

Cada ejercicio tendrá, cuando corresponda:

- `index.html`
- `styles.css`
- recursos necesarios para la consigna

## Referencias

- MDN — HTML: https://developer.mozilla.org/en-US/docs/Web/HTML
- MDN — CSS: https://developer.mozilla.org/en-US/docs/Web/CSS
